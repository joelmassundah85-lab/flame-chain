
# FLAME CHAIN

Android-first blockchain wallet prototype.

## Features
- Wallet dashboard
- Local wallet creation
- Receive address screen
- Transaction activity screen
- Security information
- Android APK build configuration

## Security
This is a prototype. It does not yet support real blockchain transfers or live mining.

Never share your recovery phrase or private key.

## Technology
- React Native
- Expo
- TypeScript
- ethers.js
- Expo SecureStore
